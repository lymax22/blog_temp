Input contract

Uses the existing ECOS standard form: minimize cᵀx, subject to Ax=b and Gx+s=h, s∈K.

G and A must be CSC objects containing rows, cols, values, colPointers, and rowIndices. When b=[], A may be omitted.

This page reuses the production ECOS WASM solver. ECOS remains single-threaded; the Worker keeps the browser UI responsive.
